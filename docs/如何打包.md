## 🎯 最简构建步骤

```bash
# 1. 克隆项目（如果还没有）
git clone https://github.com/lbjlaq/Antigravity-Manager.git
cd Antigravity-Manager

# 2. 安装依赖
npm install

# 3. 开发运行（可选）
npm run tauri dev

# 4. 打包构建
npm run tauri build
```

构建完成后，产物在 `src-tauri/target/release/bundle/` 目录。
